# Run all stability indices

Run all stability indices

## Usage

``` r
run_all_stability(df, gen_col, env_col, rep_col, trait)
```

## Arguments

- df:

  Data frame

- gen_col:

  Genotype column name

- env_col:

  Environment column name

- rep_col:

  Replicate column name

- trait:

  Trait column name

## Value

List with fitted model metadata and combined stability table
