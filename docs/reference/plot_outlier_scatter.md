# Create an outlier detection scatter plot

Create an outlier detection scatter plot

## Usage

``` r
plot_outlier_scatter(df, trait, group_col, gen_col)
```

## Arguments

- df:

  Data frame with 'is_outlier' column

- trait:

  Trait column name

- group_col:

  Group column (usually environment)

- gen_col:

  Genotype column (for labeling)

## Value

ggplot object
