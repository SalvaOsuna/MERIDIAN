# Run Finlay-Wilkinson Reaction Norms Computes the environmental index and fits regressions for each genotype.

Run Finlay-Wilkinson Reaction Norms Computes the environmental index and
fits regressions for each genotype.

## Usage

``` r
run_finlay_wilkinson(df, gen_col, env_col, trait)
```

## Arguments

- df:

  Data frame

- gen_col:

  Genotype column name

- env_col:

  Environment column name

- trait:

  Trait column name

## Value

Data frame with fitted lines and scatter data
