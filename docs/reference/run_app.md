# Run MERIDIAN

Launches the MERIDIAN Shiny application.

## Usage

``` r
run_app(...)
```

## Arguments

- ...:

  Options passed to
  [`golem::with_golem_options()`](https://thinkr-open.github.io/golem/reference/with_golem_options.html).

## Value

A Shiny application object.

## Examples

``` r
if (FALSE) { # \dontrun{
MERIDIAN::run_app()
} # }
```
