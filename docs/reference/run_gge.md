# GGE Biplot analysis using metan::gge()

GGE Biplot analysis using metan::gge()

## Usage

``` r
run_gge(df, gen_col, env_col, rep_col, trait)
```

## Arguments

- df:

  Data frame

- gen_col:

  Genotype column name

- env_col:

  Environment column name

- rep_col:

  Replicate column name

- trait:

  Trait column name

## Value

List with GGE model and imputed-cell count
