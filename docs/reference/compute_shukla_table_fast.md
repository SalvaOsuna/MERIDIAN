# Fast Shukla variance from Wricke and interaction SS

Fast Shukla variance from Wricke and interaction SS

## Usage

``` r
compute_shukla_table_fast(ge, wi = NULL)
```

## Arguments

- ge:

  GxE matrix object from build_ge_matrices()

- wi:

  Optional precomputed Wricke ecovalence vector

## Value

Data frame of Shukla variance values
