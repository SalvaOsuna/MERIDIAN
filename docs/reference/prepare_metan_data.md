# Prepare data for stability functions

Prepare data for stability functions

## Usage

``` r
prepare_metan_data(df, gen_col, env_col, rep_col, trait = NULL)
```

## Arguments

- df:

  Data frame

- gen_col:

  Genotype column name

- env_col:

  Environment column name

- rep_col:

  Replicate column name

- trait:

  Trait column name

## Value

Data frame with cleaned factor columns
