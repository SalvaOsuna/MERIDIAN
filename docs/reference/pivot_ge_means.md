# Pivot data to genotype × environment means for a given trait

Pivot data to genotype × environment means for a given trait

## Usage

``` r
pivot_ge_means(df, gen_col, env_col, trait)
```

## Arguments

- df:

  Data frame

- gen_col:

  Genotype column

- env_col:

  Environment column

- trait:

  Trait column

## Value

Wide data frame (rows = genotypes, cols = environments)
