# Compute Covariate-Phenotype Correlations

Compute Covariate-Phenotype Correlations

## Usage

``` r
compute_covariate_correlations(env_data, env_means, env_col)
```

## Arguments

- env_data:

  Environmental covariates

- env_means:

  Data frame from run_finlay_wilkinson (contains env_mean)

- env_col:

  Column name for environments

## Value

Correlation matrix
