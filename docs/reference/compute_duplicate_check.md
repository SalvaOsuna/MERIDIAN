# Check for duplicate entries in the data

Check for duplicate entries in the data

## Usage

``` r
compute_duplicate_check(df, gen_col, env_col, rep_col)
```

## Arguments

- df:

  Data frame

- gen_col:

  Genotype column name

- env_col:

  Environment column name

- rep_col:

  Replicate column name

## Value

Data frame of duplicated rows (empty if none)
